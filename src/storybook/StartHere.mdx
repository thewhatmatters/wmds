# WMDS — WhatMatters Design System

{snippets.pitch} MIT licensed.

## Install

<Source language="bash" code={snippets.install} dark />

React 18 or 19. Add `@visx/visx` for **Chart**. `styles.css` is compiled, so the app doesn't need Tailwind. To build with your own Tailwind v4 instead, import the theme after Tailwind:

<Source language="css" code={`@import "tailwindcss";\n@import "@thewhatmatters/wmds/theme.css";`} dark />

## Quickstart

<Source language="tsx" code={snippets.quickstart} dark />

Dark mode is `data-theme="dark"` on any ancestor. A client's brand is a short `brand.css` imported after `styles.css`.
