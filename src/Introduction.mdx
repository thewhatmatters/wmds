# WhatMatters Design System (WMDS)

WMDS is our Tailwind v4 theme and Storybook catalog. **Storybook is canonical** — tokens, motion, and components are specified here first; Paper is for mockups only.

## Pattern-first (not utility-first)

WMDS is **not** a utility-class-first design system. Tailwind v4 is the **engine** — tokens, package CSS, component internals. **App engineers consume patterns**, not a catalog of classes to mix freely.

## Authoring rules (building WMDS)

1. **Patterns over utilities** — export components with typed props; centralize classes in `*Styles.ts` / `semanticVariants.ts`.
2. **Storybook is the contract** — Usage, Anatomy, Best practices, named Examples per component.
3. **Interaction states** — `hover:bg-primary-hover` etc. live in Theme; components reference stable utility names internally.
4. **Simple motion → CSS** — `transition` + `motionTransition()` from `src/lib/motion.ts`.
5. **Complex motion → Motion** — gestures, layout, enter/exit via [`motion/react`](https://motion.dev/docs/react) + `motionTransitionProp()`.
6. **Always respect reduced motion** — see below.
7. **Lucide icons only** — import from `lucide-react` until further notice. Browse [lucide.dev/icons](https://lucide.dev/icons/). Not bundled — consuming apps install the peer dep.

## Motion strategy

Two layers: CSS tokens for simple effects; Motion for gestures, layout, and enter/exit.

### Layer 1 — CSS tokens (Astryx tiers)

  rows={[

    ["--duration-slow", "975ms", "Large spatial change (rare)"],

  ]}
/>

```tsx
className={`transition-colors ${motionTransition("fast")}`}
```

### Layer 2 — Motion for React

```bash
npm install motion
```

```tsx
import { motion } from "motion/react";
import { motionTransitionProp } from "@whatmatters/wmds";

<motion.button
  whileHover={{ scale: 1.02 }}
  whileTap={{ scale: 0.98 }}
  transition={motionTransitionProp("fast")}
/>
```

**Use Motion for:** gestures, `layout` / `layoutId`, `AnimatePresence`, layout enter/exit.

**Stay on CSS for:** single-property `:hover` / `:focus` changes (fast tier).

See **Foundation → Motion** and **ADR-0008** for tier guidance.

## Accessibility — reduced motion

Storybook wraps stories in `<MotionConfig reducedMotion="user">`. `global.css` also short-circuits CSS transitions when the OS prefers reduced motion.

For bespoke cases, use `useReducedMotion()` from `motion/react`.

## Atomic design

WMDS follows [Brad Frost's atomic design](https://atomicdesign.bradfrost.com/) for component composition. **Dependency flows one way** — never import up-tier.

<DocTable
  rows={[
    ["Atoms", "src/components/atoms/ — Button, Input, Badge…"],
    ["Molecules", "src/components/molecules/ — Card, Chart, Chip, Field, List…"],
    ["Organisms", "src/components/organisms/ — Table, Tab, MoreMenu…"],
    ["Examples", "src/examples/ — templates & pages (Storybook only)"],
  ]}
/>

**Rules**

1. Atoms import only `lib/`, Theme, and peers (`lucide-react`, `motion`) — no other WMDS components.
2. Molecules compose atoms and other molecules; organisms compose molecules + atoms.
3. Examples compose lower tiers — never imported by components.
4. Storybook titles: `Atoms/Button`, `Molecules/List`, `Organisms/Table`, `Examples/…`.

Planned catalog: **`src/package.manifest.ts`** → `atomicExports`. **`docs/adr/0002-atomic-design.md`**; List/Card: **ADR-0005**; Chart: **ADR-0010**; inputs: **ADR-0006**.

## Responsive (mobile-first)

Every atom, molecule, organism, and example must work on **mobile, tablet, and desktop**. Design unprefixed styles for mobile; add **`sm:`**, **`md:`**, **`lg:`** to scale up — not desktop-first `max-*` overrides.

<DocTable
  rows={[
    ["Mobile (default)", "Unprefixed utilities — 0 to 639px"],
    ["sm:", "640px+ — large phone / small tablet"],
    ["md:", "768px+ — tablet"],
    ["lg:", "1024px+ — desktop"],
  ]}
/>

**Rules:** min **44×44px** touch targets on atoms; no hover-only actions; tables scroll horizontally or reflow on mobile; review in Storybook at **Mobile / Tablet / Desktop** viewports (default canvas = Mobile).

Reference: **`src/lib/viewports.ts`**, **Foundation → Breakpoints**, **`docs/adr/0003-responsive-mobile-first.md`**.
