# WMDS docs for apps and agents

These files ship in the npm package at `node_modules/@whatmatters/wmds/docs/`. They match the installed version, so an agent in a consuming app reads them instead of guessing from memory or from a newer Storybook.

| File | What it is |
|------|------------|
| `exports.json` | Every export with its tier, category, one-line summary, Storybook page, and the ids of its patterns. Also the CSS entries, peer dependencies, planned components, and lib helpers. |
| `components.md` | The component and token contracts: props, patterns, composition rules, and what not to do. |
| `component-contracts.md` | Long-form contracts for FooterReveal, HeroTileStack, TextSequence, ScrollHorizontal, RiveHand, and PromptBar. |
| `patterns/index.json` | One row per pattern: id, Storybook title, pattern name, file. |
| `patterns/<id>.tsx` | A pattern's Show code, exactly as Storybook shows it, with a header naming the pattern and the package version. |
| `consumer-agents.md` | A block to paste into a consuming repo's `AGENTS.md` / `CLAUDE.md`. |
| `../CHANGELOG.md` | Every release, with the **Consumer actions** an app takes to move to it. |
| `../CONSUMING.md` | Install, styles, dark mode, grid, and per-component setup. |

## How to use them

1. **Find the component.** Search `exports.json` by name, category, or summary. Planned components are listed under `planned` — they do not exist yet.
2. **Read its contract** in `components.md` (and `component-contracts.md` for the six long ones).
3. **Use a pattern when one matches.** Look up the component's `patterns` ids, open `patterns/<id>.tsx`, and copy the file verbatim, header included. The header lets an upgrade find every pasted pattern (`grep -r "@whatmatters/wmds@" src`).
4. **Missing something?** Do not hand-roll it in the app. Report the gap to WMDS (see `consumer-agents.md`).

Storybook ids in these files (`?path=/story/<id>`, `?path=/docs/<id>--docs`) append to the WMDS Storybook URL.

## In the WMDS repository

`exports.json`, `components.md`, and `patterns/` are generated by `npm run docs:generate` from `src/package.manifest.ts`, `src/storybook/componentCatalog.ts`, `AGENTS.md`, and each story's Show code. CI runs `npm run check:docs` and fails when a committed file differs from Storybook. The rest of this folder — `adr/`, `audits/`, `releasing.md` — is for WMDS contributors and does not ship.
