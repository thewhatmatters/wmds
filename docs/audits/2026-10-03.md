# Repo audit — 2026-10-03

What was wrong, what changed, and which check now catches it. The short rules that follow from this live in **`AGENTS.md` → Guardrails**. Add a new dated file here for the next audit rather than editing this one.

## Fixed

| # | What was wrong | What changed | What catches it now |
|---|----------------|--------------|---------------------|
| 1 | The package built to one module. `TextSequence` registers GSAP when the module loads, and the Rive packages declare no `sideEffects` flag, so every app that imported anything loaded GSAP and Rive. Importing only `Button` bundled to 806 KB minified (250 KB gzip). | The build emits one module per source file (`preserveModules` in `vite.lib.config.ts`). ## Open

These need a decision or a change outside this repo. They are not fixed.

### Accessibility — 38 stories, 12 rules

Each is a component change, and several are design decisions. One of the 38 (**SiteNav** links during the **FooterReveal** handoff) passes on macOS and fails on the CI runner, so results for stories that end mid-scroll can differ by environment.

| Rule | Where | Likely fix |
|------|-------|------------|
| `color-contrast` | Colors (disabled text), Dialog and Panel descriptions, Toast, Intake, PitchKit, ScrollHorizontal, SiteNav links over the footer during the FooterReveal handoff | Token values for muted and disabled text; nav surface over the footer field |
| `scrollable-region-focusable` | Card pinned-height body, ScrollHorizontal and FooterReveal reduced-motion scroller, `scroll-fade-*` lists | Keyboard access for scroll regions (`tabIndex`, name, focus ring) |
| `landmark-unique`, `landmark-no-duplicate-banner`, `landmark-no-duplicate-contentinfo` | Card (`<header>` / `<footer>` outside sectioning content), Panel, SiteNav specimens | Card shell element or header element choice |
| `aria-prohibited-attr` | TextSequence (`aria-label` on `role="paragraph"`), loading Cards (`aria-label` on a plain `div`) | Visually hidden sentence for TextSequence; a role on the loading region |
| `aria-progressbar-name` | StepProgress (also in IntakeModal and the Intake pattern) | An accessible name for the progress bar |
| `aria-allowed-role`, `list` | Toast (`li role="status"`) | Status region inside the list item |
| `aria-required-children` | Tab overflow (**More** inside the `tablist`) | Move **More** outside the `tablist` |
| `aria-hidden-focus` | SiteNav mega menu, Toast stack | Focus guards and hidden layers |
| `role-img-alt` | Avatar with a blank `name` | Decorative fallback when there is no name |
